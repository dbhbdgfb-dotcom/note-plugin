> 这是一款**浏览器扩展插件**，专门用来写剧本文稿，自动给剧本里面的角色添加编号标注。

### 主要用途

1. ✍️ 文字写作：可以直接在插件窗口写剧本、故事、对话文稿。
2. 🎭 **剧本角色自动标注（核心功能）**
   - 你录入所有角色名字（支持用`|`写别名）
   - 点击【执行角色标注】，程序自动找到正文里的角色名字，给每个不同名字分配独立不重复编号，套上你自定义的标注模板。
3. 💾 内容保存：写好的文字、角色列表、模板，保存在浏览器里面，关闭窗口再打开内容不会丢失。
4. 📥 文件导出：写完剧本，可以直接导出成 `.txt` 文本文件下载保存到电脑本地。
5. 🧹 一键清空：提供按钮一键清空正文、一键清空角色列表，方便重新创作。

## ✅ 使用说明

### 一、安装方法

1. 在 Edge/Chrome 浏览器地址栏输入 `edge://extensions/`（Chrome 浏览器输入 `chrome://extensions/`）
2. 打开右上角**开发人员模式**开关
3. 点击【加载解压缩的扩展】，选中插件文件夹 `note-plugin`，完成安装
4. 在浏览器右上角拼图图标里找到本插件，可以固定到工具栏，点击图标打开记事本独立窗口

### 二、操作步骤

1. **📝 正文编辑区**：在这里输入你的剧本故事文字。
2. **🎭角色设置**：填写角色，一行一组角色，别名用竖线`|`隔开。
> 
> 示例：
> 张三 | 小张
> 李四
> 王五
> 效果：张三 = 1，小张 = 2，李四 = 3，王五 = 4，每个名字独立编号，编号不会重复
3. **🏷️标注模板**：自定义标注格式，默认模板 `{角色}(@图片{编号})`，可以按需修改。
4. 按钮功能：
   - 保存笔记：把正文、角色、模板保存到浏览器存储
   - 导出 TXT：将剧本正文导出下载到电脑
   - 执行角色标注：一键自动给剧本里所有角色加上编号标注
   - 清空正文：确认后清空写作区文字
   - 清空角色：确认后清空角色列表

## ✅ 使用场景（用在哪里）

1. 写短剧剧本、短视频脚本、小说对话，快速批量给角色做标记编号
2. 写故事文稿，需要给人物自动标注编号的创作场景
3. 随手写文字草稿，作为简易记事本文档使用

## ✅ 特点

- 独立窗口打开，点击浏览器其他页面不会自动关闭窗口，可以一直留在屏幕上写稿
- 纯本地运行，不需要联网，文字保存在你自己浏览器内
